🔬 마이크로비트 센서 탐색하기

지금 보고 있는 X·Y·Z 값은 마이크로비트의 '감각'이 느끼는 자극입니다 👀

1 마이크로비트 연결하기

코드를 넣은 마이크로비트를 USB 케이블로 컴퓨터에 연결한 뒤, 아래 버튼을 누르세요.

0단계 · 먼저 마이크로비트에 관찰용 코드를 넣어 주세요
  1. makecode.microbit.org 접속 → 새 프로젝트 → 오른쪽 위 { } JavaScript 탭
  2. microbit_sensor_observe_code.js 파일의 내용을 전체 복사해서 붙여넣기
  3. USB로 연결한 뒤 [다운로드] → 마이크로비트 화면에 물음표(?) 가 흐르면 준비 끝
코드를 넣지 않으면 USB를 꽂아도 값이 하나도 오지 않아, 연결이 안 되는 것처럼 보입니다.
😴
연결 안 됨
아직 마이크로비트에서 값이 오지 않았어요 (0단계 코드 설치를 먼저 확인해 주세요)

⚠️ 이 프로그램은 Chrome 또는 Edge 브라우저에서만 동작합니다.
마이크로비트에는 microbit_sensor_observe_code.js 코드가 미리 들어 있어야 합니다.
🙂 연결에 성공하면 마이크로비트 화면에도 웃는 얼굴이 켜집니다.

6 티처블 머신 AI에게 물어보기

티처블 머신에서 만든 이미지 모델의 주소를 붙여넣으면, 웹캠이 보는 모습을 AI가 무엇이라고 판단하는지 볼 수 있어요. 마이크로비트는 움직임으로, AI는 눈(카메라)으로 같은 동작을 알아맞히는 셈입니다.

아직 시작하지 않았어요

📌 모델 주소 만드는 법: teachablemachine.withgoogle.com → 이미지 프로젝트 → 동작마다 사진을 찍어 학습 → [모델 내보내기] → 업로드(공유 가능한 링크) → 나오는 주소를 복사해서 위 칸에 붙여넣기
📌 이 기능만은 인터넷 연결과 웹캠 사용 허용이 필요합니다. 카메라 허용 창이 뜨면 [허용]을 눌러 주세요.
📌 카메라는 https:// 주소로 열었을 때만 켜집니다. 파일을 더블클릭해서 열었다면 수업 서버 주소로 열어 주세요.

📣 다음 시간에는 이 센서 값을 모아서 AI를 학습시켜볼 거예요!
