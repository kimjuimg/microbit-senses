차이를 학생들이 직접 확인해 볼 수 있도록 만들었습니다.

## 준비물

- **Chrome 또는 Edge** 브라우저
- 앞의 세 앱은 **카메라 또는 마이크 허용**이 필요합니다
- 앞의 세 앱은 [티처블 머신](https://teachablemachine.withgoogle.com)에서 만든
  **모델 주소**가 있어야 합니다 (만드는 방법은 각 앱 안에 적어 두었습니다)
- 네 번째 화면은 아무 준비물 없이 바로 쓸 수 있습니다

## 개인정보

카메라 영상과 마이크 소리는 **학생 컴퓨터의 브라우저 안에서만** 처리됩니다.
어떤 서버로도 전송되지 않고, 어디에도 저장되지 않습니다.
각 앱의 설정(모델 주소, 알림 문구 등)만 그 컴퓨터의 브라우저에 저장됩니다.

## 마이크로비트 코드

`microbit_sensor_observe_code.js` 는 마이크로비트가 센서 값(가속도·기울기·온도·밝기)을
0.1초마다 보내도록 하는 코드입니다.
[MakeCode](https://makecode.microbit.org) 에서 `{ } JavaScript` 탭에 붙여넣고
보드에 다운로드해서 씁니다.

> 마이크로비트가 연결되지 않을 때는, **이 코드가 보드에 설치되어 있는지부터** 확인해 주세요.
> 코드가 없으면 USB를 꽂아도 값이 하나도 오지 않아 연결이 안 되는 것처럼 보입니다.
